# Lore and character tracking for Deadline Season 2

## Character text editor

Open `character-editor.html` through a local web server (for example, VS Code Live Server). The editor loads `database/characters.json`, lets you select a character and reincarnation, and provides fields for their text. Choose **Download updated characters.json** when finished, then replace `database/characters.json` with the downloaded file. Browsers do not let a page overwrite a local JSON file directly.
